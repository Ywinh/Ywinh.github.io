# 关于

这是一个使用 MkDocs Material 搭建的中文博客。

目前已经完成这几个基础能力：

- 顶部导航栏
- 首页博客流
- 左侧最近文章列表
- 自动生成归档和分类

只需要持续往 `docs/blog/posts/` 里写文章即可。

文章建议使用如下头部格式：

```md
---
date: 2026-04-01
categories:
  - 随笔
tags:
  - MkDocs
  - Blog
---
```

首页、归档页、分类页现在会自动截断长文，所以你可以先直接写正文。

如果你以后想手工控制摘要边界，仍然可以在正文里加：

```md
<!-- more -->
```

这样列表页会优先按这行之前的内容作为摘要。
