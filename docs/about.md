# 关于

这是一个使用 MkDocs Material 搭建的中文博客。

目前已经完成这几个基础能力：

- 顶部导航栏
- `Blog` 技术文章流
- `Life` 生活文章流
- 左侧按栏目显示文章标题

后续写作时：

- 技术类文章放到 `docs/blog/posts/`
- 生活类文章放到 `docs/life/posts/`

文章建议使用如下头部格式：

```md
---
date: 2026-04-01
tags:
  - MkDocs
  - Blog
---
```

栏目首页现在会自动截断长文，所以你可以先直接写正文。

如果你以后想手工控制摘要边界，仍然可以在正文里加：

```md
<!-- more -->
```

这样列表页会优先按这行之前的内容作为摘要。
